# 3D Portfolio Workspace

The actual Next.js app is inside:

```text
3d-portfolio-main/
```

Run it from that folder:

```bash
cd 3d-portfolio-main
pnpm install
pnpm dev
```

Local URL:

```text
http://localhost:3000
```

Siddharth Singh's portfolio data lives in:

```text
3d-portfolio-main/src/data/config.ts
3d-portfolio-main/src/data/constants.ts
3d-portfolio-main/src/data/projects.tsx
```
